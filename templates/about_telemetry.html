Looking at sessions

On the main page click "last" on the KartSim card, which will open an overview of today's sessions.

This gives an idea in which turns time is lost, where consistency can be improved. And "Theoretical best" shows what time you could achieve if you were extremely consistent: it takes the best pieces from your laps and stitches them together.

This gives good quick guidance, but we can dig deeper by clicking on a specific turn (or on a "Map" button) and compare individual laps, to understand where exactly time is lost.

Setting up the plugin

Please read the terms of use.

To send telemetry you need to install an rFactor 2 plugin. The latest version can be obtained on the GitHub releases page. The installer provides a nice GUI that will guide you. It is also used for adjusting settings and uninstalling. I tried to make the UI self-explanatory, but if something is not clear, let me know and I'll try to make it better.

The installer will ask for an API key; your key is {{ get_current_key() }}

You can configure the plugin to only send sessions from a certain kart or add driver name overrides (but API keys are bound to certain drivers). The plugin also saves all the sessions on your drive locally, so they can be re-uploaded later from the installer if needed.

The next time you run the simulator, the session should be streamed to the server and should appear in the Web UI. The data is live-streamed but you would need to refresh the page to see new data.

The track layouts should be there for all UK KartSim tracks, but I'm still marking up turns, thus per-turn analytics may not be available on some tracks.
